# Support

Product help for VeloTrak is by email: [support@velotrak.app](mailto:support@velotrak.app).

The [terms of service](https://velotrak.app/terms/) say support depends on the plan: community, email, or priority. On the pricing page, Pro includes email support and Team includes priority support. Updates are included while a paid plan is active.

## Before you write

- Version: `/opt/velotrak/velotrak version`
- What you expected and what happened
- The install path you used (official installer, a pinned release, or your own PostgreSQL and ClickHouse)

Leave license keys, database passwords, and click exports out of the email unless support asks for a specific value.

## Look first

- [Installation](docs/installation.md) — v1.0.0 assets, the install command, upgrades
- [FAQ](docs/faq.md)
- Website FAQ and pricing: https://velotrak.app/#faq and https://velotrak.app/#pricing
- Read-only demo (no sign-up): https://demo.velotrak.app/admin/#email=demo%40velotrak.app&password=admin123
- Licenses you already bought: https://velotrak.app/license/

## This repository

GitHub Releases is where the Linux binaries are published: https://github.com/VeloTrak/Velotrak/releases

The application source is not in this repo. Release notes for v1.0.0 are copied in [CHANGELOG.md](CHANGELOG.md). Security reports go to the same support address; see [SECURITY.md](SECURITY.md).
